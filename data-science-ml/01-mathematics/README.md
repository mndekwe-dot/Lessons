# Mathematics

**Weeks 5-9 of `../CURRICULUM.md`.** Read in numbered order.

The phase people skip, and the one that decides whether you can tell a real result from noise for the rest of your career. Only what is load-bearing - no integrals by hand, ever.

| # | File | Core? | What it gives you |
|---|---|---|---|
| 01 | [01-LINEAR_ALGEBRA.md](01-LINEAR_ALGEBRA.md) | **core** | Vectors, matrices, shapes, the dot product as similarity, eigen for PCA. |
| 02 | [02-STATISTICS.md](02-STATISTICS.md) | **core** | Distributions, sampling, standard error, hypothesis testing, and what a p-value is not. |
| 03 | [03-PROBABILITY.md](03-PROBABILITY.md) | **core** | Conditional probability, Bayes, base rates, why 98% accuracy can be worthless. |
| 04 | [04-CALCULUS_FOR_ML.md](04-CALCULUS_FOR_ML.md) | **core** | Derivatives, gradients, the chain rule - which IS backpropagation. |
| 05 | [05-OPTIMISATION.md](05-OPTIMISATION.md) | *extra* | Gradient descent variants, learning rates, convexity. Read after 04. |
| 06 | [06-EXPERIMENT_DESIGN.md](06-EXPERIMENT_DESIGN.md) | **core** | A/B testing done properly: power, sample size, peeking, guardrail metrics. The most commonly interviewed applied skill in a data role. |
| 07 | [07-CAUSAL_INFERENCE.md](07-CAUSAL_INFERENCE.md) | *extra* | "Did X cause Y?" when you cannot randomise. DAGs, difference-in-differences, RDD, instruments, matching. Read after 06. |

Files 06 and 07 are the applied half of statistics. File 02 teaches you what a p-value
is; file 06 teaches you how to run something worth computing one on, and file 07 what
to do when an experiment is impossible — which, for questions about children's
education, it usually is.
