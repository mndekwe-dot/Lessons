# 12 — Daily Practice Plan: Be Self-Reliant at Coding

**Goal:** You should be able to look at any GCA problem and know exactly what to do — without looking at notes, hints, or solutions. This comes from reps, not reading.

---

## How to Use This Plan

1. **Do NOT look at solutions until you have tried for 15+ minutes.** If you're truly stuck after 15 min, read the matching section in `08-cheat-sheet.md` (NOT the solution file).
2. **Type every line yourself.** Copy-paste teaches nothing.
3. **Run the tests after every change.** Don't wait until the end.
4. **If a test fails, read the error.** Then fix your code. Do not immediately check the solution — struggle is where learning happens.
5. **Do the drills every day for the first 2 weeks.** After that, rotate to focus on your weak spots.

## The Self-Reliance Checklist

Before checking any solution, ask yourself:

1. **What type of loop do I need?** (Transform / Filter / Reduce / Best-so-far / Search / Count-each)
2. **What data structure?** (list, dict, set, grid)
3. **Do I need two passes?** (Count first, then decide)
4. **Where does return go?** (AFTER the loop unless SEARCHING)
5. **Have I tested with the given examples?**
6. **Have I tested edge cases?** (empty input, single element, all-same values)

If you can answer all 6 from memory, you're ready.

---

## Practice Rules

- **No looking at solutions during the 15-minute attempt.** Stuck? Read the cheat sheet section, try again.
- **Do NOT run the solution file** — that's cheating during practice.
- **After you solve**, compare your code with the solution file — learn ONE thing you did differently.
- **Track your scores** — note how many tests pass each run. You should see improvement week over week.
- **Speed comes later.** First accuracy, then speed.
