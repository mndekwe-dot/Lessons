## The Single Most Important Fact About the GCA

The 4 questions are **not random** — they always follow the same difficulty ladder:

| Question | Type | Recommended Time | Difficulty | Passing Target |
| :--- | :--- | :--- | :--- | :--- |
| **Q1** | Basic coding (loops, if/else, math) | 5–10 min | Very easy | **MUST PASS** |
| **Q2** | Data manipulation (lists, strings, counting) | 10–15 min | Easy | **MUST PASS** |
| **Q3** | Implementation-heavy (2D grids, simulations) | 15–20 min | Medium (careful reading) | **MUST PASS** |
| **Q4** | Problem solving (optimal hash maps, sets) | 20–25 min | Harder (bonus score) | Bonus points |

## GCA Pass Strategy

**Your pass strategy: lock in Q1 + Q2 + Q3.** That is 3 correct = passing score. Q4 is a bonus.
- **Q1 (Warmup):** Finish quickly in 5–10 minutes.
- **Q2 (Data):** Careful string/list manipulation in 10–15 minutes.
- **Q3 (Careful Implementation):** Read the rules twice and handle 2D coordinates/edge cases.
- **Q4 (Optimal DS):** Only attempt after Q1–Q3 are green.
